`sets.report.json` is the unmodified output of `weft prove examples/sets.weft`
(Weft 0.1.0, development build) from the public Weft repository. It has four
checks: `known_members`, `at_least_one` and `has_inputs` are entailed, and
`wider_domain` is undetermined. All are hypothetical. The trial tests use it as
a real `weft.report/1` document.
