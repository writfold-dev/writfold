# Language guidelines for commit messages

- Write the subject as an imperative sentence without a final full stop:
  "Batch ledger writes", not "Batched ledger writes.".
- Say what changed and why; leave how to the diff.
- Use plain words. Explain an abbreviation the first time it appears.
- For an external audience, name no internal host, ticket or codename;
  describe the effect instead ("the staging ledger", "the retry bug").
